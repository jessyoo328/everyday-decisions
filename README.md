# Everyday decisions study

Online study page for a research study at the Terry College of Business, University of Georgia (version s2-1.1.0). Everything is in `index.html`.

- **Live link:** https://jessyoo328.github.io/everyday-decisions/
- **Prolific link:** add `?PROLIFIC_PID={{%PROLIFIC_PID%}}&STUDY_ID={{%STUDY_ID%}}&SESSION_ID={{%SESSION_ID%}}`
- **Test run:** add `?test=1` (rows are marked as tests, and timers are skipped)

Responses are saved to the research team's database when a participant submits. The key in the page can only add responses; it cannot read them.
